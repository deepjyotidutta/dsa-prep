## Pattern Quick Reference

| Pattern | Key Signal in Problem | Template Idea |
|---------|----------------------|---------------|
| Two Pointers | Sorted array, pairs, palindrome | left=0, right=n-1 |
| Sliding Window | Substring, subarray, window size | expand right, shrink left |
| Binary Search | Sorted input or search space | lo=0, hi=n, mid=(lo+hi)//2 |
| BFS | Shortest path, level order | queue + visited set |
| DFS | All paths, connected components | recursive + visited |
| Backtracking | All combinations/permutations | choose, explore, unchoose |
| DP | Optimal substructure, overlapping subproblems | dp[i] = f(dp[i-1], ...) |
| Heap | Top-K, streaming median | min/max heap |
| Monotonic Stack | Next greater/smaller element | stack of indices |
| Union-Find | Connected components, cycle detection | parent[], rank[] |
| Trie | Prefix search, word dictionary | TrieNode with children[] |
| Topological Sort | DAG ordering, dependencies | Kahn's BFS or DFS+stack |

## Complexity Cheat Sheet

| Operation | Array | HashMap | Heap | BST (balanced) | Graph BFS/DFS |
|-----------|-------|---------|------|----------------|---------------|
| Access | O(1) | O(1) | O(log n) | O(log n) | — |
| Search | O(n) | O(1) | O(n) | O(log n) | O(V+E) |
| Insert | O(n) | O(1) | O(log n) | O(log n) | — |
| Delete | O(n) | O(1) | O(log n) | O(log n) | — |
